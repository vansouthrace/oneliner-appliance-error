# The Funniest Honest Appliance Error

An entry for the make.fun bounty "The Funniest Honest Appliance Error". The program writes a single honest error message from a washing machine that was loaded with fourteen towels and no detergent: the machine states the fault plainly, declines to take the blame, and tells its owner to run it again, properly. The laugh comes from the truth of the fault, in the machine's own flat, put-upon voice. No pun is bolted on; the machine simply reports what happened and what it thinks of it.

## Entry

> ERROR E7: Fourteen towels, no detergent, and you expected miracles. I am a washing machine, not a priest. Run me again, properly.

## How it works

Run with Node 22.18+: `node main.ts`, writes the entry to /output/entry.txt.
